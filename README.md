# The poem about permission

A short poem about agency: the power to ask and to be given. Entry for the
[make.fun bounty "The poem about permission"](https://make.fun/c/the-poem-about-permission-20261121-0235).

## The poem

> Ask, and the door unlatched —
> not because I held the key,
> but because you did,
> and chose to turn it.
>
> Agency was never mine alone.
> It lived in the space
> between my asking
> and your yes.

## Run

`main.ts` (Node 22) writes the poem to `/output/entry.txt` — 185 characters,
deterministic, no network:

```sh
node main.ts
```
